لوحة الإدارة ← ⚽ المباريات: تكتب الفريقين والبطولة والوقت وتختار

قائمة مباريات كل المشتركين فوراً بعلامة ⭐، وبضغطة وحدة يشتغل

لوحة الإدارة ← 📡 روابط القنوات ← 🩺 ابدأ فحص كل القنوات —
يجرب روابط كل قناة عبر سيرفر التطبيق ويعرض لك جدول: ✅ شغالة
/ ❌ مقطوعة، مع عداد وشريط تقدم. سيرفك يرد: تعرف مين رابط
مقطوع قبل ما يشكو المشتركون.

■ ملاحظة سحابية:
المتجر ومباريات الإدارة ينحفظون بمجموعتين جداد بـ Firebase:
store و custom_matches — مفحوصة وتشتغل بقواعد مشروعك الحالية.

■ ليش القنوات ما اشتغلت بالنشر السابق (العلامة الحمراء)؟

لأنك رفعت ملف app.html وحده، فصار الموقع "ثابت" (Static) بدون سيرفر.
القنوات تحتاج السيرفر عشان البروكسي /api/hls (سيرفرات البث تحجب المتصفح
مباشرة CORS)، والمباريات تحتاج /api/matches.

فحصنا موقعك bashar-alsalosi-internet-communicat.vercel.app والنتيجة:
   الصفحة الرئيسية  ✅ تشتغل (200)
   /api/matches     ❌ 404 NOT_FOUND
   /api/hls         ❌ 404 NOT_FOUND
بدونهم كل قناة تفشل وتطلع العلامة الحمراء.

هذي الحزمة تحتوي المشروع كامل مع السيرفر — انشرها وكل شي راح يشتغل.

■ محتوى الحزمة (لا تحذف ولا تغير اسم أي ملف):

   bashar-vercel/
   ├─ package.json                ← تعريف المشروع (حتى Vercel يعرف يبنيه)
   ├─ next.config.ts              ← إعدادات البناء
   ├─ tsconfig.json
   ├─ next-env.d.ts
   ├─ .gitignore
   ├─ README-DEPLOY.txt           ← هذا الملف
   ├─ version.json                ← رقم النسخة للتحديث التلقائي (ارفعه بـ GitHub مع app.html)
   ├─ public/app.html             ← التطبيق نفسه (81 قناة)
   └─ src/
      ├─ app/route.ts             ← يحوّل الصفحة الرئيسية / إلى التطبيق
      └─ app/api/
         ├─ hls/route.ts          ← بروكسي البث المباشر (القنوات)
         └─ matches/route.ts      ← جلب المباريات والقناة الناقلة

 الطريقة الأولى — الرفع عبر GitHub (المستودع المربوط بـ Vercel)
════════════════════════════════════════════════════════════

1) فك ضغط الملف bashar-vercel-deploy.zip بيطلعلك مجلد bashar-vercel

2) ادخل على مستودعك في GitHub

3) احذف الملف القديم (app.html أو index.html الموجود بجذر المستودع):
      افتح الملف ← ايقونة السلة (Delete) ← Commit changes

4) اضغط "Add file" ← "Upload files"

5) اسحب كل "محتويات" مجلد bashar-vercel داخل صفحة الرفع:
      المجلد src  +  المجلد public  +  الملفات (package.json و next.config.ts
      و tsconfig.json و next-env.d.ts و .gitignore و README-DEPLOY.txt)
   ⚠️ مهم: اسحبهم كلهم بضربة وحدة حتى يرفعهم بنفس الشجرة (src/app/api/...)

6) اكتب وصف Commit (مثلاً: نشر المشروع كامل مع السيرفر) واضغط Commit changes

7) ارجع على Vercel — راح يبني وينشر تلقائياً خلال 2-4 دقائق.
   لو ما انشر تلقائياً: Deployments ← أحدث نشر ← النقاط الثلاث ⋯ ← Redeploy

════════════════════════════════════════════════════════════
 الطريقة الثانية — إذا نشرت من الترمينال (vercel CLI)
════════════════════════════════════════════════════════════

بعد فك الضغط، من داخل مجلد bashar-vercel نفّذ:

   npm i -g vercel
   vercel login
   vercel --prod

════════════════════════════════════════════════════════════
 التحقق بعد النشر (مهم)
════════════════════════════════════════════════════════════

1) افتح رابط موقعك — المفروض تفتح صفحة الدخول البنفسجية

2) افحص السيرفر: افتح   رابط-موقعك/api/matches
   - طلعت مباريات بصيغة JSON؟  ✅ السيرفر شغال والقنوات راح تشتغل
   - طلع NOT_FOUND؟           ❌ الرفع ناقص — أعد الخطوات وتأكد من مجلد src

3) جرّب أي قناة — لازم تشتغل مثل ما تشتغل على جهازك تماماً

■ ملاحظات:
- أول عملية بناء على Vercel تاخذ 2-4 دقائق، بعدها تصير أسرع.
- لا ترفع مجلدي node_modules أو .next (أصلاً مو موجودين بالحزمة).
- أي تعديل مستقبلي على GitHub ينشر تلقائياً على Vercel.
- النسخة الحالية: 1.10.0 — 81 قناة (الوان سبورت 1-6 أولاً ثم beIN
  1-9 ثم الباقي) + خيارين سينمانا/قنوات + اسم التطبيق على البث
  + متجر ومباريات تتحكم بيها من لوحة المدير + فحص القنوات.

════════════════════════════════════════════════════════════
 🆕 الجديد بالإصدار 1.9.13 — حل التقطيع + اللوقو + الشعارات + حفظ الدخول
════════════════════════════════════════════════════════════

■ حل التقطيع (أهم تعديل):
سبب التقطيع كان أن روابط البث الأساسية بصيغة TS مستمرة، وبروكسي
Vercel يوقف كل اتصال بعد 60 ثانية (حد خطة المجاني) فتنقطع القناة
كل دقيقة. الحل: كل روابط mdmfista صارت m3u8 (بث مجزأ) — كل طلب
قصير وما تنقطع. حتى روابط لوحة الإدارة القديمة بصيغة ts تنحوّل
تلقائياً إلى m3u8 بدون ما تعدل شي. وأضفنا:
- مراقب تجمد للبث: إذا وقفت الصورة يعيد الاتصال لحاله وبعدها
  يجرب السيرفر التالي بدون تدخل من المشترك.
- كاش خفيف على حافة Vercel للمقاطع — يقلل الحمل ويسرّع البث
  لما يكثر المشتركين على نفس القناة.
- ملف السيرفر src/app/api/hls/route.ts انرفع مدته إلى 300 ثانية.

■ اللوقو الرسمي بالهيدر:
نفس اللوقو المرفق (أيقونة مربعة بإطار ذهبي وزر تشغيل أخضر ونقطة
حمراء + اسم بتدرج ألوان) والعنوان صار: بشار الالوسي لخدمات الانترنت.

■ شعارات القنوات:
رجعت أيقونة جانب اسم كل قناة: لوقوات حقيقية مضمّنة داخل التطبيق
لعائلة beIN وXTRA وEurosport وRed Bull وFox Sports 2، ولوقوات
خارجية للقنوات المفتوحة، وشارات ملونة (TOD / ألوان / TENNIS...)
للباقي — وإذا أي لوقو خارجي فشل يرجع الإيموجي تلقائياً.

■ معلومات الاشتراك صارت بالطول:
حالة الاشتراك والبداية والانتهاء والديون كل وحدة بسطر لحالها.

■ زر Enter:
الضغط على Enter من كيبورد الهاتف/الكمبيوتر يسجل الدخول مباشرة،
وكذلك من نموذج طلب التفعيل.

■ خيار حفظ اليوزر والباسورد:
مربع «حفظ اليوزر والباسورد على هذا الجهاز» (مفعل تلقائياً) —
للمشترك وللمدير: أول ما يفتح التطبيق تلقى البيانات معبية لحالها
والشاشة على نفس النوع (مشترك/مدير). إذا شال الصح ينسى البيانات.

■ طريقة التحديث من GitHub (نفس طريتك):
1) GitHub ← المستودع ← public/app.html ← قلم التعديل ✏️
2) امسح القديم كامل والصق ملف app-v1.9.13.html كامل
3) Commit changes — وVercel ينشر تلقائياً خلال 2-4 دقائق
4) (موصى به) كرر نفس الشي لملف src/app/api/hls/route.ts
   بالصق محتوى ملف api-hls-route.ts المرفق
5) بعد النشر: افتح رابط موقعك/api/matches — إذا طلعت مباريات
   JSON فكل شي تمام، وكل المشتركين بيحصلون التحديث تلقائياً
   عند فتح التطبيق (ما تحتاج ترسل التطبيق لأحد).

════════════════════════════════════════════════════════════
 ميزة جديدة: استيراد قنواتك من ملف خارجي من داخل التطبيق
════════════════════════════════════════════════════════════

ما عاد تحتاج تعديل الكود إذا تغير مزود القنوات:

   لوحة الإدارة ← 📡 روابط القنوات ← 📥 استيراد قائمة قنوات كاملة

1) حط رابط قائمة مزودك (رابط get.php أو أي رابط m3u / m3u_plus)
2) اضغط "📥 استيراد الآن"
3) التطبيق يفك القائمة ويرتبها: الوان سبورت أولاً ثم beIN SPORTS 1
   ثم 2-9 ثم بقية القنوات الرياضية، ويحفظها بالسحابة
4) القائمة توصل لكل المشتركين تلقائياً عند فتح التطبيق
5) زر "↩️ رجوع للقائمة الأصلية" يرجعك للقائمة المدمجة (81 قناة)

مثال رابط get.php (من لوحة مزودك):
   http://سيرفر-المزود:8080/get.php?username=اليوزر&password=الباسورد&type=m3u_plus

ملاحظة: روابط "تحديث روابط القنوات بالأرقام" تنطبق على القائمة
الأصلية فقط. إذا مستورد قائمة خارجية، حدّث روابطها من نفس رابط
القائمة (أعد الاستيراد) أو رجع للقائمة الأصلية أولاً.
